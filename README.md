# Dollar Tree (dollar-tree)

Dollar Tree is a leading operator of discount variety stores in North America, operating more than 16,000 stores under the Dollar Tree and Family Dollar brands. The company offers a broad assortment of products at value price points, serving customers across the United States and Canada. Vendor integration runs through the Dollar Tree Vendor Portal and EDI/SAP/ERP systems; no public REST API is currently available.

## APIs

### Dollar Tree Vendor Portal

Dollar Tree provides a vendor portal for supplier partners to manage orders and product information. Integration is handled through EDI, SAP, and ERP systems. No public REST API is currently exposed.
